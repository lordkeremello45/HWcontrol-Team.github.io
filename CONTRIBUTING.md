# Contributing to HWcontrol Team

Thank you for helping improve HWcontrol2.0 and its documentation. Contributions should make the product easier to install, safer to use, more accessible or more reliable.

## Useful first contributions

- Test a published beta release on a real supported operating system and report reproducible results.
- Improve platform-specific installation instructions or explain a limitation clearly.
- Check accessibility, keyboard navigation, contrast, broken links and small-screen layouts.
- Review localization for correctness and context rather than translating strings mechanically.
- Improve technical articles with reproducible steps and trustworthy references.

## Before submitting a change

1. Search existing issues and documentation.
2. Describe the user problem and the observable evidence.
3. Keep changes focused and avoid unsupported product claims.
4. Do not include secrets, private logs, device serial numbers or personal file paths.
5. For security vulnerabilities, do not publish exploit details in a public issue; follow the project's security policy.
6. Run the site build and smoke checks when changing this website.

Run the following commands from the repository root: npm install, npm run build, npm run check:site.

## Community and promotion

We do not buy stars, fabricate users, post repetitive advertisements, or present a beta feature as generally supported. Technical answers on Stack Exchange should solve the question being asked; mention HWcontrol2.0 only when it is genuinely relevant and disclose the relationship to the project.

## Product limitations

HWcontrol2.0 is beta software. Hardware control depends on device, driver, firmware, operating system and permissions. A documentation or website change must not imply that a feature works on every machine without evidence.
